# Bike-rental-demand-prediction
End-to-end bike rental demand project using the Capital Bikeshare dataset (2011-2012). Includes full EDA, statistical tests, and a comparison of 11 regression models with cross-validation and tuning to predict daily rentals from weather and seasonal data. Best model: RBF-kernel SVR (R² ≈ 0.91). Built with Python and scikit-learn.
